### 2. 子表命名与总表有区别，单独放入文件夹 ✅
命名规则：

- 总表 ： YYYY年MM月党费收缴明细表.xlsx
- 子表 ： YYYY年MM月-支部名称-党费收缴子表.xlsx （增加了支部名称和"子表"标识）
- 汇总表 ： YYYY年MM月党费汇总表.xlsx
### 3. 新添加导入外部表格功能 ✅
新增文件：

- excel_importer.py - Excel文件导入模块
- word_importer.py - Word文件导入模块
修改的文件：

- main.py - 新增菜单选项"12. 导入外部表格数据"
- requirements.txt - 新增 python-docx>=0.8.11 依赖
导入功能特点：

功能 说明 导入Excel明细表 导入包含所有支部所有党员的总表，支持合并单元格 导入Excel子表 导入每个工作表对应一个支部的子表格式 导入Word汇总表 解析Word文档中的汇总表格，仅显示统计信息 自动检测 根据文件名和结构自动判断文件类型

导入模式：

1. 追加 - 在现有数据基础上添加新数据
2. 替换 - 删除现有数据，使用导入的数据
3. 合并 - 合并同名支部的党员
智能解析特性：

- 自动检测表头行位置
- 支持多种列名别名（如"住房公积金"、"公积金"）
- 自动跳过合计行和空行
- 如果Excel中没有缴费基数或党费，自动根据工资和扣款计算
## 使用方法
### 运行系统
```
python main.py
```
### 导入外部数据
1. 在主菜单选择 "12. 导入外部表格数据"
2. 选择导入类型：
   - 1. 导入Excel明细表（总表）
   - 2. 导入Excel子表（各支部表）
   - 3. 导入Word汇总表（仅查看统计）
   - 4. 自动检测并导入
3. 输入文件路径
4. 选择导入模式（追加/替换/合并）
### 安装Word依赖（如需导入Word文件）
```
pip install python-docx
```
